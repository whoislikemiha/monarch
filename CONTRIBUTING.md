# Contributing

Monarch is a public portfolio and experimentation project. It is shared openly so
others can read the code, learn from it, and try it out — not as a product with a
support commitment.

## Building and running

See the [README](./README.md) for setup, build, and development instructions.

## Issues and discussion

Issues and discussions are welcome. Bug reports, questions, and ideas are all fair
game — feel free to open one. Expect informal, best-effort responses.

## Pull requests

Pull requests are welcome as a way to start a conversation, but please note that they
may not be merged. This project moves in whatever direction its exploration takes, so
a change that is perfectly reasonable in isolation may still not fit the current
direction. If you are considering a substantial change, open an issue first so we can
talk it through before you invest the time.

## Style

- Match the conventions already present in the surrounding code.
- Keep commits focused: one logical change per commit.
