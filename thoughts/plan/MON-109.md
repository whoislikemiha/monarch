# MON-109: P4 Slice C — Nested timeline and Now UI

## Goal

Render the P4 action narrative that MON-107 stores and MON-108 emits. The captain should see coherent actions as the top-level execution story, with nested tool calls, outcomes, and decisions available without reading raw JSON.

## Scope

1. Add a read-only working-memory command for `agent_working_memory`.
2. Extend the quest store to keep per-agent L2 current/recent actions fresh.
3. Render nested quest events in `QuestTimelineTool`:
   - `coherent_action` parent rows;
   - child `tool_call` rows with status, duration, and previews;
   - child `action_outcome` rows;
   - child `executor_decision` rows.
4. Add a compact Agent View "Now" strip backed by L2:
   - current action;
   - current quest path;
   - last few recent actions.

## Out of Scope

- Durable execution plan UI (P4b).
- Full Inspector/detail panel for quest event payloads.
- E2E automation; use unit/build checks plus manual app testing.

- `npx svelte-check`
