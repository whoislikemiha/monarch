# MON-117 — P5 Slice B: quest detail editor UI and refs panel

Linear: [MON-117](https://linear.app/monarch-commander/issue/MON-117/p5-slice-b-quest-detail-editor-ui-and-refs-panel)

## Goal

Make MON-116's rich quest backend visible in the Quests toolbox tool. The
captain should be able to edit a quest's what/why fields, record manual quest
events, and attach external references without leaving the quest timeline.

## Scope

1. Extend `questStore` with P5 commands:
   - `db_update_quest_manual`
   - `db_record_manual_quest_event`
   - `db_list_quest_refs`
   - `db_create_quest_ref`
   - `db_update_quest_ref`
   - `db_delete_quest_ref`

2. Add per-quest refs state and subscribe to `quest-refs-{questId}` while a
   quest is visible.

3. In `QuestTimelineTool.svelte`, add an expanded-quest detail editor:
   - status and grade controls
   - scope, current direction, rationale, summary
   - change-rationale field for semantic event payloads

4. Add compact manual event capture for:
   - `note`
   - `blocker`
   - `blocker_resolved`
   - `question`
   - `answer`

5. Add a refs panel with add/list/delete for:
   - `url`
   - `linear`
   - `github_issue`
   - `github_pr`
   - `file`
   - `artifact`

## Acceptance

- Expanded quests show editable rich fields from `QuestRow`.
- Saving the brief calls the manual update path and refreshes tree/events.
- Manual events render as readable timeline rows rather than raw JSON.
- Quest refs can be added and deleted, and the refs panel refreshes.
- `npx svelte-check`, `npm test`, and `npm run build:web` pass.

## Out of scope

- Full dedicated Quest detail page.
- File picker / Linear / GitHub autocomplete.
- Chat-shadow or Architect consumption of question/answer events.
- P6 quest report UI.
