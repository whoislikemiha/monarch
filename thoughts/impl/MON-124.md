# MON-124 — Execution timeline: implementation notes

PR: https://github.com/whoislikemiha/monarch/pull/106 (16 commits)

## What was implemented

The workspace timeline went from a working-memory recency buffer (last ≤10 actions) to the real "watch the work" surface: a **flat, chronological, paginated record** of everything the shadow did and is doing, read top-down like the chat (bottom-anchored, scroll up for the past).

- **Backend feed**: `db_list_agent_timeline(agent_id, before, limit)` — cursor-paged on top-level `objective_events` (`(created_at, id)` newest-first) joined via `objective_nodes.assignee_shadow_id` (`kind='objective'`); each page carries its nested children and objective metadata. Registered in Tauri + specta + WS dispatch.
- **Frontend**: `timelineStore.svelte.ts` (paged feed, debounced head refresh on `objective-event` pings, append-only backwards), `timelineModel.ts` (payload parsing, segment grouping, live tool merge), rebuilt `TimelinePane`/`TimelineAction` plus new `TimelineToolRow`, `TimelineMilestone`, `TimelineReportCard`, `ToolActivityChip`, and the `EventIcon` primitive in `src/lib/ui/`.
- **Narration model** (settled during review): `set_current_action` is the one grouping mechanism — opens a chunk, tools nest under it, pivots open the next, `complete_action` closes. Objective-free: events with no current objective land on a silent per-agent **scratch objective** (`scratch-{agent_id}`). Unnarrated tool calls persist **top-level** and render as bare rows. Shadow prompt rewritten accordingly (`shadow-oath.ts`).
- **Chat de-tooling**: `ToolGroupBlock` deleted; tool groups render as one-line chips that scroll/flash the matching timeline row (by `tool_call_id`). Meta tools (narration/plan) never render as work — not as rows, not in chips.
- **Artifacts**: tool-call payloads persist a normalized `target` (path/command, extracted from full args at record time); opening a scoped chat records a durable `chat_spawned` child event → chips on the card that reopen the conversation.
- **Visual system**: event-icon set (shape-first), the 4 prompt-pack backport fixes (weighted action glyph, decision = fork not diamond, tree indent to depth 5, RTL head-truncated paths), Catalog panel.

## Key decisions

- **Narration augments the stream; it never gates it.** A synthetic "unnarrated work" grouping card was built and replaced with bare chronological rows at Miha's direction.
- **No text harvesting.** An auto-harvest of assistant prose into action headlines was built, then deliberately removed ("why do we have static checks like checking on '?'") — explicit mechanisms over inference heuristics. See memory `monarch-timeline-design-principles`.
- **Scratch objective over a schema change** for objective-free events — reuses all existing machinery (feed join, events, working memory); realizes the roadmap's deferred scratch-campaign seam at per-agent granularity. CLAUDE.md's "project-less stays ephemeral" rule updated.
- **Active = streaming.** An unclosed action on an idle agent renders dashed/unresolved with a static time, not a ticking clock.
- **History-sourced fallback rows** (chat-history executions with no `objective_events` record) only classify as unrecorded once the feed is fully loaded, to avoid mislabeling deep narrated history.

## Bugs found & fixed while dogfooding

- **Wake-after-restart context loss** (pre-existing ui-v2 regression): `LiveBinding` captured `sourceSessionId` at bind time, but `spawnStoppedAgent` sets it after mount → `load_session_context` never fired; the LLM started blank while the UI showed history. Handler now reads the live store value.
- Restored tool executions: `parse_timestamp` returns seconds, stamped into a ms field (epoch "20595d" rows); restored args are JSON strings — target extraction now parses them, with an args-preview fallback.
- Tool-group display items rendered in every chat pane (turn filtering only keyed user turns) — moot once tables left the chat.

## What was left out

- Pause/resume controls on NOW (P3 two-organs); chat-shadow `investigation` events (P3).
- Per-shadow timeline projections / crew attribution (Arc II) — seams kept: events carry actor/author, action-card children are heterogeneous.
- Click-to-diff on file chips (deferred ui-v2 phase — chips list paths).
- `ObjectiveTimelineTool` dock inspector untouched (dissolves into Projects-view objective detail later).
- Event retention/pruning; `db_list_objective_events` pagination for the inspector.
