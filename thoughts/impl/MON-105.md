# MON-105 — Auto-create active quest for meaningful user turns

Linear: [MON-105](https://linear.app/monarch-commander/issue/MON-105/auto-create-active-quest-for-meaningful-user-turns)
Plan: [thoughts/plan/MON-105.md](../plan/MON-105.md)

## What shipped

Meaningful user turns now create a quest spine automatically:

1. **Prompt-path auto-create.** `AgentManager::send_command` inspects outgoing `prompt` commands before they hit the sidecar. If the prompt looks like actual work and the agent has no active current quest, Rust creates a root quest.
2. **Atomic current quest write.** `Database::auto_create_current_quest_internal` inserts the root `quest_nodes` row, seeds the creation `quest_events` row, and updates `agents.current_quest_id` in one transaction.
3. **Conservative heuristic.** Chitchat/short pings are ignored. Task verbs, code/work language, multiline prompts, or sufficiently detailed prompts create a quest. Classifier output is still advisory and later; this slice deliberately avoids blocking the user turn waiting for it.
4. **Timeline wake-up.** Auto-created roots emit `quest-created-for-agent-{agentId}`. `questStore` listens on that per-agent channel even when the root list is empty, so the Quest Timeline refreshes when the first quest appears.
5. **Roadmap/docs.** The cognition roadmap now includes the P2b bridge slice, and ONBOARDING documents the new quest-created channel.

## Key decisions

- **Create before sidecar work starts.** MON-103 and Keeper provenance need `agents.current_quest_id` before events arrive, so waiting for classifier completion would be too late.
- **Root only.** No decomposition, child quests, or Architect behavior. This just makes the spine exist.
- **Terminal current quests are replaced.** If `current_quest_id` points at a terminal quest (`done`, `verified`, `abandoned`, `superseded`), the next meaningful turn can create a new current root.
- **Manual creation unchanged.** Existing `db_create_quest` still works; it now also emits the per-agent creation event when an assignee is present.

- Executor `suggest_memory` tool (MON-102).
- Classifier-driven routing/decomposition.
- LLM-generated quest titles.
- Linking persisted `messages.quest_id` to the current quest.
