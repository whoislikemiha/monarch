# MON-109: P4 Slice C — Nested timeline and Now UI

## Summary

MON-109 renders the P4 action narrative in the frontend:

- Quest timeline now treats `coherent_action` as the parent execution row.
- Nested `tool_call`, `action_outcome`, and `executor_decision` events render as child rows.
- Agent View shows a compact "Now" strip from L2 working memory.

## Backend Surface

Added read-only `db_get_working_memory(agent_id)` over Tauri and WebSocket fallback. The command returns `WorkingMemoryPayload` from `agent_working_memory`, which keeps Agent View from reconstructing L2 from event rows.

The generated TypeScript bindings now include:

- `WorkingMemoryPayload`
- `WorkingMemoryCurrentAction`
- `WorkingMemoryRecentAction`

## Frontend

`questStore` now refreshes `workingMemory` alongside quest roots and refreshes L2 after visible quest-event notifications. It also subscribes to quest-event channels for every visible quest in the loaded trees, not only root quests.

`QuestTimelineTool` now groups events by `parentEventId` and renders:

- action parent row with intent/status/outcome;
- tool child rows with tool name, status, duration, args preview, and result preview;
- outcome child rows with auto-close indicator;
- decision child rows with optional rationale.

`AgentView` imports `questStore`, refreshes the current agent's quest/L2 state, and renders a compact "Now" strip below the message list when current or recent actions exist.
