# MON-117 — P5 Slice B implementation notes

## What was implemented

- `questStore` now wraps the MON-116 P5 commands for manual quest updates,
  manual quest events, and quest refs.
- Per-agent quest state now caches `refsByQuest` and listens on
  `quest-refs-{questId}` for expanded quests.
- Expanded quest rows in `QuestTimelineTool` now include:
  - a brief editor for status, grade, scope, current direction, rationale, and
    summary;
  - a change-rationale input that feeds semantic quest-change events;
  - a references panel with add/list/delete;
  - a manual event form for notes, blockers, questions, and answers.
- P5 quest-change/manual event rows render as readable timeline entries instead
  of raw JSON payloads.

## Key decisions

- **Inline editor, not a new tool yet.** V0 lives inside the existing expanded
  quest detail so the captain can edit in context while reading the timeline.
- **Refs support add/delete in V0.** Store support includes update, but the UI
  keeps inline reference editing out of this slice to avoid dense controls.
- **Status uses the existing storage enum.** The dropdown mirrors MON-83's
  current statuses instead of introducing new display-only lifecycle names.
- **Browser smoke was limited.** The Vite app shell rendered in the in-app
  browser, but no local shadow/quest data was available and the Rust WebSocket
  backend was not running in browser mode.
