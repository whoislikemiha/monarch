# Security Policy

Monarch is a personal, open-source project. There is no formal support commitment or
response-time SLA, but security reports are taken seriously and appreciated.

## Reporting a vulnerability

Please report vulnerabilities privately rather than opening a public issue:

- Open a private security advisory via GitHub
  ([Security → Report a vulnerability](https://github.com/whoislikemiha/monarch/security/advisories/new)), or
- Contact the maintainer through their GitHub profile.

Please include enough detail to reproduce the issue — affected version or commit,
steps to reproduce, and the potential impact.

## What to expect

This is a personal project maintained on a best-effort basis, so there is no
guaranteed response time. Reports will be reviewed and addressed as time allows.
Please avoid publicly disclosing a vulnerability until it has had a chance to be
looked into.
